🐾 NekoRoginSP 1.0.0<br/>
<br/>
🐾 概要<br/>
 Ragnarok Online (jRO) のアカウント管理 ＆ Webのログイン画面を毎回開かなくてもいい ねこの手アプリですにゃ！<br/>
<br/>
🐾 なにができるのかにゃ？<br/>
 ブラウザからのWebログインをスキップできますにゃ！<br/>
 複数アカウントの切り替えもスムーズにできますにゃ！<br/>
<br/>
🐾 必要なソフト<br/>
 アプリを使うには .NET Framework 4.8 がいるにゃ！<br/>
 ここから落としてにゃ → https://dotnet.microsoft.com/ja-jp/download/dotnet-framework/net48<br/>
<br/>
🐾 動作環境<br/>
 Windows 7 SP1 以上<br/>
<br/>
 もし Windows 7 SP1 を使ってるにゃら、以下の更新が必要ですにゃ！<br/>
