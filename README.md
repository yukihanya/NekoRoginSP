🐾 NekoRoginSP 1.0.2.0<br />
<br />
🐾 概要<br />
 Ragnarok Online (jRO) のアカウント管理 ＆ Webのログイン画面を毎回開かなくてもいい ねこの手アプリです。<br />
<br />
🐾 何ができるの？
 ブラウザからのWebログインをスキップできます。<br />
 複数アカウントの切り替えもスムーズにできます。<br />
 <br />
🐾 必要なソフト<br />
 アプリを使うには .NET Framework 4.8 が必要です。<br />
 ダウンロード先URL → https://dotnet.microsoft.com/ja-jp/download/dotnet-framework/net48<br />
 <br />
🐾 動作環境<br />
 Windows 7 SP1 以上<br />
<br />
 もし Windows 7 SP1 を使ってるなら以下の更新が必要です。<br />
 KB3140245 / KB4474419 / KB4490628 / EasyFix51044<br />
<br />
🐾 このソフトウェアはネコミミウェアです<br />
 利用する場合は、ネコミミ系衣装(猫耳のヘアバンド、子犬のヘアバンドなど)を自分のキャラさんに装備させなければなりません。<br />
<br />
🐾 メモ<br />
 ショートカットキーを有効にするとAlt+1～9で対応した位置のIDでゲームを起動できます。 <br />
